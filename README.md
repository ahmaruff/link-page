# Link Page — Teddy Sheringham

Link in bio sederhana yang dibuat di kelas Web 101: Build Your Own Link Page.

🔗 **Live:** https://ahmaruff.github.io/link-page/

## Fitur
- Daftar link dengan filter kategori
- Tambah link lewat form (hanya sementara, tidak disimpan)
- Dark mode (tersimpan di browser)
- Responsif untuk HP dan desktop

## Teknologi
HTML, Tailwind CSS (via CDN), JavaScript.

## Cara menjalankan
Buka folder dengan VS Code, lalu jalankan dengan ekstensi **Live Server**.
Catatan: jangan dibuka langsung lewat file:// karena `fetch` butuh server.
